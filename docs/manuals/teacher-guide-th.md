# คู่มือครู — ClassQuest

> ClassQuest ใช้ **คู่กับ** Google Classroom ไม่ได้มาแทน ครูยังประกาศและสื่อสารใน Classroom ได้ตามเดิม

## 1. เริ่มต้น
1. เปิดเว็บ ClassQuest → **เข้าสู่ระบบด้วย Google** (บัญชีสถานศึกษา)
2. ครั้งแรกจะเห็นหน้า "รอการอนุมัติ" — ผู้ดูแลระบบจะกำหนดสิทธิ์ "ครูผู้สอน" ให้

## 2. สร้างรายวิชา
1. เมนู **จัดการรายวิชา › สร้างรายวิชา** กรอกรหัส ชื่อ ระดับ ห้อง ภาคเรียน ปี พ.ศ. → ระบบสร้าง 18 สัปดาห์ให้
2. หน้ารายวิชา › **ออกแบบหน่วยและบทเรียน**: แก้ชื่อหน่วย, เพิ่มบทเรียน, กำหนดขั้น QUEST (Q-U-E-S-T), บทเรียนที่ต้องเรียนก่อน, เพิ่มสื่อ (YouTube, Google Drive/Slides, PDF, โค้ด, Wokwi)
3. **เผยแพร่** ทั้งหน่วยและบทเรียน แล้วเปลี่ยนรายวิชาเป็น "เผยแพร่"
4. ภาคเรียนใหม่ใช้ **คัดลอกไปภาคเรียนใหม่** (ไม่คัดลอกนักเรียนและผลการเรียน)

## 3. ให้นักเรียนเข้าร่วม
- **รหัสเข้าร่วม**: หน้ารายวิชา › สร้างรหัส (กำหนดวันหมดอายุ/จำนวนครั้ง) → แจกหรือแปะใน Google Classroom
- **นำเข้ารายชื่อ CSV**: เมนู Google Classroom › เลือกไฟล์ที่มีคอลัมน์อีเมล → นักเรียนจะถูกลงทะเบียนและอนุมัติเป็นนักเรียนเมื่อเข้าสู่ระบบครั้งแรก
- ใส่ **ลิงก์ Google Classroom** ของห้อง เพื่อให้นักเรียนกดไปได้

## 4. ภารกิจ (Quest) และการตรวจงาน
1. หน้ารายวิชา › **จัดการภารกิจ › สร้างภารกิจ**: ประเภท (Main/Side/Daily/Weekly/Challenge/Boss), ความยาก, คะแนนเต็ม, **XP (แยกจากคะแนน)**, กำหนดส่ง, วิธีส่ง (ข้อความ/ลิงก์/ไฟล์ ≤ 2 MB/ส่งใน Classroom), จำนวนครั้งที่ส่งได้, ภารกิจที่ต้องผ่านก่อน
2. บันทึกแล้วตั้ง **Rubric** และผูกแต่ละเกณฑ์กับสมรรถนะ
3. เมนู **ตรวจงาน**: ให้คะแนนตาม Rubric + Feedback → **อนุมัติ** (นักเรียนได้ XP ครั้งเดียว) หรือ **ส่งกลับให้แก้ไข**

## 5. แบบทดสอบ
1. หน้ารายวิชา › **แบบทดสอบ › คลังข้อสอบ** สร้างคำถาม (ปรนัย/ถูก-ผิด/เติมคำ) ผูกสมรรถนะได้
2. **สร้างแบบทดสอบ** เลือกประเภท Pre-test / Post-test / Quiz, เวลา, สุ่มข้อ, จำนวนครั้ง, เวลาเปิด–ปิด, เวลาแสดงเฉลย
3. ข้อเติมคำที่ไม่มีคำตอบที่ยอมรับ ครูให้คะแนนที่ **ดูผลและตรวจข้อเขียน**
4. **เปรียบเทียบก่อน–หลังเรียน** แสดงผลรายคน (รหัสนิรนามได้), ค่าเฉลี่ย, S.D., normalized gain, CSV

## 6. สมรรถนะ
- หน้ารายวิชา › **สมรรถนะ**: กำหนดรหัส ชื่อ เกณฑ์ผ่าน สมรรถนะหลัก (Skill Tree) และภารกิจที่เป็นหลักฐาน
- **ตารางสมรรถนะ** เห็นว่าใครผ่าน/ต้องพัฒนา/ยังไม่ประเมิน → คลิกชื่อเพื่อดูรายงานและบันทึกผลสอบปฏิบัติ

## 7. เกม: XP, เลเวล, Badge, Leaderboard
- **เลเวลและ XP**: ใช้มาตรฐานหรือกำหนดเองต่อรายวิชา
- **Badge**: อัตโนมัติ (ระบบ) + สร้างเอง/มอบให้นักเรียน (เช่น ช่วยเหลือเพื่อน)
- **Leaderboard**: ปิดโดยค่าเริ่มต้น เปิดในหน้ารายวิชา (ผู้ดูแลต้องเปิดทั้งระบบด้วย) นักเรียนเลือกเข้าร่วมเอง แสดงเฉพาะชื่อเล่น

## 8. Virtual Lab
หน้ารายวิชา › **Virtual Lab**: ใส่ลิงก์โปรเจกต์ Wokwi ขั้นตอน แผนภาพ โค้ด ผลที่คาดหวัง และผูกภารกิจสำหรับส่งหลักฐาน

## 9. ติดตามผลและการประกวด
- **ภาพรวม**: อัตราเรียนจบ ภารกิจ งานรอตรวจ Pre/Post สมรรถนะ และ **นักเรียนที่ควรได้รับการช่วยเหลือ** พร้อมเหตุผล
- **Google Classroom › ส่งออกคะแนน CSV** (ครูนำไปกรอกเอง ระบบไม่เขียนกลับ)
- **หลักฐานการประกวด**: 13 หมวด + แบบประเมินความพึงพอใจ + **รายงานพร้อมพิมพ์ (PDF)** และ CSV — ใช้รหัสนิรนาม ห้ามใส่ชื่อจริง

## 10. ข้อควรระวัง
- XP ไม่ใช่คะแนนผลสัมฤทธิ์ อย่านำไปตัดเกรดโดยตรง
- ข้อมูลผลการเรียนทั้งหมดมาจากการใช้งานจริง ระบบไม่สร้างข้อมูลแทน

# คู่มือครู (ร่าง — จะเติมเมื่อฟีเจอร์เสร็จ)
1. เข้าสู่ระบบด้วย Google → รอผู้ดูแลอนุมัติเป็น "ครู"
2. สร้างรายวิชา → ระบบสร้าง 18 สัปดาห์ให้อัตโนมัติ → จัดกิจกรรมตามขั้น QUEST
3. สร้างรหัสเข้าร่วม (Enrollment Code) แจกนักเรียน หรือแปะใน Google Classroom
4. สร้างภารกิจ/แบบทดสอบ ผูกสมรรถนะ → เผยแพร่
5. ตรวจงานที่ "ตรวจงาน" ใช้ Rubric → ระบบให้ XP อัตโนมัติ
6. ดู Dashboard, Export CSV, รวบรวมหลักฐานที่ "ศูนย์หลักฐานการประกวด"

# คู่มือนักเรียน (ร่าง)
1. เข้าสู่ระบบด้วยบัญชี Google ของสถานศึกษา
2. กรอกรหัสเข้าร่วมรายวิชาจากครู
3. เรียนตามแผนที่ QUEST → ทำภารกิจ → ส่งงาน (ข้อความ / ลิงก์ / ไฟล์ไม่เกิน 2 MB)
4. รับ XP และ Badge เมื่อครูตรวจผ่าน — XP ไม่ใช่คะแนนเก็บ
5. ดูสมรรถนะของตนเอง และสร้าง Portfolio (เป็นส่วนตัวโดยค่าเริ่มต้น)

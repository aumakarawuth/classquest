# คู่มือนักเรียน — ClassQuest

## 1. เข้าสู่ระบบ
- ใช้ **บัญชี Google ของสถานศึกษา** เท่านั้น
- ถ้าเห็น "รอการอนุมัติ" ให้รอครู/ผู้ดูแล แล้วกด "ตรวจสอบอีกครั้ง"

## 2. เข้าร่วมรายวิชา
เมนู **รายวิชาของฉัน** → กรอก **รหัสเข้าร่วม** จากครู (หรือถ้าครูนำเข้ารายชื่อแล้ว รายวิชาจะขึ้นเอง)

## 3. เรียนตามเส้นทาง QUEST
- **Q** ตั้งคำถาม → **U** ทำความเข้าใจ → **E** ทดลอง → **S** แก้ปัญหา → **T** ถ่ายทอด
- หน้ารายวิชาบอกบทเรียนถัดไป (ปุ่ม "เรียนต่อ") บทที่มีกุญแจต้องเรียนบทก่อนหน้าให้จบก่อน
- อ่านจบแล้วกด **ทำเครื่องหมายว่าเรียนจบ** (ได้ XP)

## 4. ภารกิจ
- เมนู **ภารกิจ**: ต้องทำ / รอตรวจ / ผ่านแล้ว
- ส่งงานเป็นข้อความ ลิงก์ (https เช่น Google Drive, Wokwi) หรือไฟล์ PNG/JPEG/WebP/PDF ไม่เกิน 2 MB — งานใหญ่ส่งเป็นลิงก์ Google Drive
- ถ้าครูให้ส่งใน Google Classroom จะมีปุ่มพาไป
- ครู "ส่งกลับให้แก้ไข" → แก้แล้วส่งใหม่ได้ตามจำนวนครั้งที่กำหนด ดู Feedback ในประวัติการส่ง

## 5. แบบทดสอบ
- อยู่ในหน้ารายวิชา › แบบทดสอบ กด **เริ่มทำ** (มีเวลาจำกัดถ้าครูตั้งไว้)
- คำตอบบันทึกไว้ในเครื่องระหว่างทำ ถ้าหน้าปิดไป ให้กลับมากด **ทำต่อ**
- เฉลยจะแสดงเมื่อถึงเวลาที่ครูกำหนด
- **Pre-test ไม่มีผลต่อเกรด** ตอบตามความเข้าใจของตนเอง

## 6. Virtual Lab
เมนู **Virtual Lab** → เปิดใน Wokwi → ทำตามขั้นตอน → ส่งลิงก์โปรเจกต์และภาพผลลัพธ์เป็นหลักฐาน

## 7. XP, เลเวล, Badge และสัปดาห์แห่งการเรียนรู้
- XP สะท้อนการลงมือเรียนรู้ **ไม่ใช่คะแนนเก็บ**
- Badge ได้อัตโนมัติเมื่อทำตามเงื่อนไข หรือครูมอบให้
- **สัปดาห์แห่งการเรียนรู้** นับสัปดาห์ที่มีการเรียนจริง ขาดได้ 1 สัปดาห์โดยไม่หาย และไม่มีการหัก XP
- Leaderboard (ถ้าครูเปิด) ต้องเลือก "แสดงฉัน" เอง ใช้ชื่อเล่น — ไม่ควรใช้ชื่อจริง

## 8. สมรรถนะและแฟ้มสะสมผลงาน
- **สมรรถนะของฉัน**: Skill Tree และหลักฐาน (ผ่าน / ต้องพัฒนา / ยังไม่ประเมิน)
- **แฟ้มสะสมผลงาน**: ปักหมุดผลงานเด่น เขียนสะท้อนผล พิมพ์เป็น PDF — เป็น **ส่วนตัวโดยค่าเริ่มต้น** เลือกแชร์ให้ครูได้ (บันทึกสะท้อนผลครูผู้สอนอ่านได้เพื่อการประเมิน)

## 9. ความเป็นส่วนตัว
เพื่อนร่วมชั้นไม่เห็นคะแนน งาน หรือแฟ้มของคุณ แบบประเมินความพึงพอใจแบบไม่ระบุตัวตน ครูเห็นเฉพาะผลรวม
